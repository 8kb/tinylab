# eval_bundle/

The unpacked DCLM CORE evaluation bundle (`core.yaml`, `eval_data/`, ...), exactly as
[benchcore](https://github.com/8kb/benchcore) expects to find it under `<base_dir>/eval_bundle/`. The
original `eval_bundle.zip` is not stored.

Rules: [`tinylab/docs/remote.md`](https://github.com/8kb/tinylab/blob/main/docs/remote.md).
